项目目标： 创建一个名为“许愿柳（The Wishing Willow）”的暗黑风格单页Web应用，致敬电影《痴迷》的诡异美学。 技术栈要求： 前端：纯原生 HTML + CSS + JavaScript（无需框架）。 后端：你已有自己的 API 接口（请预留 /api/make-wish 的 POST 请求路径，请求体为 { "wish": "用户愿望" }，响应需符合下文 JSON 格式）。为方便调试，请在代码注释中注明后端接口地址替换位置。 视觉与风格（暗黑哥特风）： 色调：深空黑（#0a0a0f）、暗夜蓝黑（#0d1321）、血色高光（#8b0000）、暗金（#b8860b）、枯木棕（#3e2723）。 背景：动态粒子烟雾效果（使用 Canvas 或 CSS 动画实现飘渺的薄雾），一轮朦胧的暗红色月亮悬于左上角。 核心元素——许愿柳：使用 CSS 或 SVG 绘制一棵形态扭曲、枝条下垂的枯柳。树干需有逼真的纹理感（可用 CSS 阴影与渐变模拟）。 排版：使用衬线字体（如 Cinzel 或 Times New Roman），文字带有微弱的暗影发光。 核心交互逻辑（方案A - 点击折断）： 页面中央为许愿柳，下方为输入框（Placeholder：在此写下你渴望的...）和“掰断它”按钮。 用户输入愿望并点击按钮： 按钮立即禁用，防止重复提交。 折断动画（关键）：柳树的一根主要枝条触发“折断”特效——枝条产生裂纹，树干震动，伴随一段 CSS 碎片粒子飞溅的效果，持续约 1.5秒。折断后柳枝缓缓垂落。 动画播放期间，页面显示“交易正在缔结...”的加载字样。 动画结束后，前端调用后端 API 发送愿望。 收到 API 返回的 JSON 数据后，渲染 “代价契约”展示区。 “代价契约”展示区布局（方案B）： 位于柳树下方或右侧，采用并排双栏设计（暗金边框，羊皮纸纹理背景）： 左栏：标题“【许愿原文】”，内容显示用户输入的愿望。 右栏：标题“【扭曲的代价】”，内容显示 API 返回的 price 字段（带有打字机逐字出现的效果，增强诡异感）。 契约底部添加一行小字：“愿望已兑现，代价已刻入因果”。 动效要求： 页面加载时柳树有轻微摇曳动画（sway 关键帧）。 代价文字逐字出现时，背景的暗红月亮闪烁一下。 鼠标悬停按钮时有暗金火焰光晕。 响应式： 适配 PC 和移动端。
